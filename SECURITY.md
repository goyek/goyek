# Security Policy

## Supported versions

Security fixes are provided for the latest `v3` release. Users should update
to the latest patch release before reporting a problem.

| Version | Supported |
| ------- | --------- |
| Latest `v3` release | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue or discussion.
Use [GitHub private vulnerability reporting][report] instead.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Avoid including sensitive data that is not needed to understand the
report.

If private vulnerability reporting is unavailable, open a public issue that
asks the maintainers for a private contact method without disclosing details of
the vulnerability.

[report]: https://github.com/goyek/goyek/security/advisories/new
